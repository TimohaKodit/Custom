# Custom

Десктоп-виджет для Windows: компактная панель поверх других окон с карточками на тёмном полупрозрачном фоне.

## Что это

Приложение показывает две вещи:

- **Этот ПК** — загрузка процессора, память, диски, аптайм и самые тяжёлые процессы. Данные берутся напрямую из системы.
- **Claude Code** — расход токенов за 5-часовое окно, за день и за неделю, с разбивкой по проектам и моделям. Считается из локальных логов Claude Code (`%USERPROFILE%\.claude\projects`), файлы только читаются и никогда не изменяются.

Всё считается локально, на вашей машине. Ни своего сервера, ни интернета, ни аккаунта, ни API-ключей приложению не нужно.

## Установка

1. Откройте страницу [Releases](https://github.com/TimohaKodit/Custom/releases).
2. Скачайте файл `.msi` из последнего релиза.
3. Запустите его и пройдите установку.

**Про предупреждение Windows.** Приложение не подписано сертификатом разработчика — сертификат платный. Поэтому при запуске установщика Windows SmartScreen покажет окно «Windows защитила ваш компьютер» и напишет «Неизвестный издатель». Чтобы продолжить:

1. Нажмите **«Подробнее»**.
2. Нажмите появившуюся кнопку **«Выполнить в любом случае»**.

Это ожидаемое поведение для любой неподписанной программы.

## Сборка из исходников

Что нужно установить:

- **Node.js 20+**
- **Rust stable** — проще всего через `winget install Rustlang.Rustup`, toolchain `stable-x86_64-pc-windows-msvc`
- **Visual Studio Build Tools 2022** с компонентом «Разработка классических приложений на C++»
- **WebView2** — уже входит в Windows 10 и 11, отдельно ставить не нужно

Дальше:

```powershell
npm install

# запуск в режиме разработки
npm run tauri dev

# сборка установщиков (.msi и NSIS .exe)
npm run tauri build
```

Готовые установщики появятся в `src-tauri/target/release/bundle`. Первая сборка долгая — Rust компилирует все зависимости с нуля.
